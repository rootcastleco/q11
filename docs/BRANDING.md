# Project identity

Q11 Linux Bring-up is an independent embedded Linux project maintained by
**[Batuhan Ayrıbaş](https://batuhanayribas.com)**. The GitHub namespace remains
`rootcastleco/q11`; project-facing attribution and the canonical website use
`batuhanayribas.com`.

Use **Q11 Linux Bring-up** as the project name and **Batuhan Ayrıbaş · Engineering
& Research** as the attribution. Write project documentation and tool messages in
English. Preserve firmware output, technical names and historical capture bytes
as evidence rather than translating them.

## Visual asset

The [repository header](../assets/brand/q11-header.svg) is a lightweight, editable
SVG with accessible title/description and no external fonts or scripts. Its chip
outline is illustrative, not a Q11 pinout or wiring diagram.

| Role | Color |
|---|---|
| Background | `#111916` |
| Main text | `#F4F6EE` |
| Secondary text | `#BEC9BF` |
| Research accent | `#B7D4A0` |

These are the repository's visual choices, not a specification for the website.
Keep status wording visible when reusing the header. Do not replace "unverified"
with a success claim before a captured hardware milestone establishes it.

## Attribution and voice

Use precise observations, short explanations and reproducible commands. Separate
host validation from target-device validation. Preserve references to upstream
projects and their authors; personal branding does not imply ownership of vendor
firmware, Linux, Debian, HiLoot or third-party research. Huawei and HiSilicon are
hardware references, not sponsors or affiliations.
